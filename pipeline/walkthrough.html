LEARN RSA pipeline

One numbered, config-driven script set that goes from raw BIDS to the three findings. AFNI GLM, no spatial smoothing, run-wise valence-split feedback betas. 33 subjects, 4 runs. This page is the exact map: every script, the command that runs it, what goes in, what comes out, and where the data sit on the cluster.

The three findings

Trait social anxiety (SCARED-C social, dimensional) reshapes how the brain represents peer feedback across a learning session. All three land on rostral and mid-cingulate medial frontal cortex.

1 · Model Alignment RSA
rACC peer representations sharpen across runs with SA
b=+.032, t=+3.62, p=.0007, q=.025
2 · Temporal ISC
Higher SA, BOLD drifts from the group (idiosyncrasy)
rACC ρ=−.53 q=.052, aMCC ρ=−.50 q=.059
3 · Whole-brain ISC
One Schaefer-400 survivor, dorsal medial frontal
RH_Cont_Cing ρ=−.65, q=.017

The interactive report with every ROI, brain viewer, and table is analysis/new-v2/index.html.

Config, one source of truth

Every script sources pipeline/config.sh. Change a path or the subject list there and nowhere else.

TOPDIR=/data/projects/STUDIES/LEARN/fMRI
RSA=$TOPDIR/RSA-learn
BIDS=$TOPDIR/bids                              # raw BIDS, never modified
SSW=$TOPDIR/derivatives/afni/ssw               # anatomical warps, per subject

01Fix events

01_fix_events.py. Relabels missed-prediction feedback events to their canonical peer-by-feedback labels, so every feedback trial carries a valence (mean or nice) and a peer. Reads raw BIDS, writes a corrected copy. The raw BIDS stays untouched.

in bids/out events_fixed/
python3 pipeline/01_fix_events.py \
  --bids-dir $BIDS --out-dir $EVENTS_FIXED \
  --report $RSA/reports/nopred_fix_report.tsv --mode majority

02Make timing

02_make_timing.sh. Turns the corrected events into run-wise AFNI .1D timing files: feedback split by valence and peer per run, plus prediction, response, and the prediction-to-feedback anticipation window. This is the pre-enrichment timing that matches the validated betas. An intermediate enriched event set altered the prediction and response regressors and weakened the effect, so it is not used.

in events_fixed/out timing/ (per subject .1D)
bash pipeline/02_make_timing.sh          # reads config, writes $TIMING

03GLM

03_glm.sh. For each subject, afni_proc.py builds and runs the single-subject pipeline, then 3dDeconvolve fits the run-wise valence-split design (41 regressors). No spatial smoothing, because RSA needs unsmoothed multivoxel patterns. Idempotent: a subject whose stats file exists is skipped. This is the heavy step, roughly 20 to 40 minutes per subject. Run it on CR2.

in bids/ + timing/ + ssw/out <id>.results.feedback_runwise_glm/ (betas + pb04)
bash pipeline/03_glm.sh              # all subjects
bash pipeline/03_glm.sh 1055 958     # a subset

Processing blocks and warp, taken straight from the engine lib/_afni_proc_engine.sh:

afni_proc.py -subj_id $subj \
  -dsets .../sub-${subj}_task-learn_run-0{1,2,3,4}_bold.nii.gz \
  -blocks despike tshift align tlrc volreg mask scale regress \
  -copy_anat anatSS.$subj.nii -anat_has_skull no \
  -tlrc_base MNI152_2009_template_SSW.nii.gz \
  -tlrc_NL_warped_dsets anatQQ.nii anatQQ.aff12.1D anatQQ_WARP.nii \
  -volreg_align_to MIN_OUTLIER -volreg_align_e2a -volreg_tlrc_warp \
  -regress_censor_motion 1 -regress_censor_outliers 0.1 \
  -regress_stim_times NonPM_*_fdk*_run*.1D  ...        # no blur block, on purpose
The scale block output pb04.*.scale+tlrc is the input to the ISC steps. It is the mean-scaled, warped, unsmoothed timeseries, before regression.

04Model alignment and temporal ISC

04_model_alignment_and_temporal_isc.py. Two analyses over 36 a priori social-brain ROIs (30 cortical 10mm spheres plus 6 Harvard-Oxford subcortical structures).

Finding 1, Model Alignment RSA. Per subject and run, build a 4-by-4 neural RDM across peers from the feedback betas, correlate it with the peer-identity model RDM, and Fisher-z. Fit z ~ run + SA + run:SA. The interaction is tested with a joint shuffle: SA swapped between subjects and z scrambled across runs, 10000 permutations. BH-FDR across 36 ROIs.

Finding 2, Temporal ISC. Leave-one-out ISC on the warped pb04 timeseries. Per subject, ROI, and run: warp the full 217-TR series to the group-median feedback onsets, z-score, correlate with the mean of the other 32, Fisher-z. Average the per-run ISC across runs. Spearman against SA, BH-FDR. The per-run then average design is what reproduces the reported numbers, not a concatenated series.

in betas + pb04 + learn_clinical.csvout results/al18_hybrid_{learning_rsa,temporal_isc}.json
python3 pipeline/04_model_alignment_and_temporal_isc.py --n-perm 10000

05Whole-brain ISC

05_wholebrain_isc.py. The same warped, per-run-averaged temporal ISC test extended to all 400 Schaefer-400 cortical parcels, for whole-brain context and correction. Parcel-mean the pb04 series, warp per run, z-score, leave-one-out ISC per run, average across runs, Spearman against SA, BH-FDR across 400. One parcel survives, a dorsal medial frontal parcel next to the aMCC sphere.

in pb04 + Schaefer-400 atlas (nilearn) + learn_clinical.csvout results/wholebrain_400_temporal_isc_results.json
python3 pipeline/05_wholebrain_isc.py
The atlas is Schaefer-400 2mm from nilearn, resampled to the data grid. The original run used an uploaded copy of the same published atlas. Both give the survivor at ρ=−.65, q=.017.

Run it

bash pipeline/run_all.sh              # everything, raw BIDS to results
bash pipeline/run_all.sh --analysis   # skip 01-03, re-run only 04-05

Every step skips finished work, so re-running is cheap. The full script set is in pipeline/. The original ISC producers, ported faithfully into steps 04 and 05, are kept for provenance in archive/original-isc-producers/ on the clusters.
