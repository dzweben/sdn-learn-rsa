Step 5

What Beta Maps Are

Understand how beta maps are produced and how we extract ROI-level values from them.

Concept

Beta maps are statistical images from the GLM. Each beta map is a 3D brain volume where every voxel contains the estimated response strength for one condition.

Our GLM produces 41 beta maps per subject — one for each condition:

  • 32 run-wise feedback betas: 8 peer/feedback conditions across 4 runs
  • 8 prediction/response betas: 4 peer conditions x prediction + response
  • 1 anticipation beta: the interval between prediction and feedback

Where They Live

Beta maps are stored inside each subject's stats file:

derivatives/afni/IndvlLvlAnalyses/<id>/<id>.results.LEARN_RSA_runwise_AFNI/stats.<id>+tlrc

This is an AFNI dataset with ~130 sub-bricks. The beta coefficients are in sub-bricks labeled <condition>#0_Coef (e.g., FBM.Mean60.r1#0_Coef).

From Beta Maps to ROI Values

For RSA and behavioral analyses, we don't work with whole-brain beta maps directly. Instead, we extract the average beta within each ROI:

  1. Take a beta map (one 3D brain volume for one condition)
  2. Apply an ROI mask (e.g., vmPFC, Amygdala)
  3. Compute the mean beta across all voxels in the mask
  4. Store that single number in a CSV

This is what Stage 4 does — it turns 41 whole-brain beta maps into 41 numbers per ROI, repeated for 8 ROIs and 38 subjects.

Two Ways to Extract: Means vs. Patterns

The pipeline extracts beta maps in two complementary ways:

Stage 4: ROI Means

Average the beta across all voxels in the mask → one scalar per condition per ROI.

Tool: 3dROIstats -nzmean

Output: 8 CSV files in ROI_extractions/

Use for: behavioral correlations, group-mean plots.

Stage 5: Voxel Patterns

Keep every voxel's beta → one vector per condition per ROI.

Tool: 3dmaskdump + 1dtranspose

Output: 304 .1D files in ROI_patterns/

Use for: RSA (the core analysis of this project).

Why does RSA need patterns? RSA computes similarity between conditions by correlating their multi-voxel activation patterns. A single mean collapses all spatial information. The pattern preserves which voxels responded strongly and which didn't — that's where the representational structure lives.

Product 1: ROI Mean CSVs (Stage 4)

After Stage 4, each ROI has a CSV like this:

Subject,FBM.Mean60.r1,FBN.Mean60.r1,...,Anticipation.PredFdk
958,0.1234,0.2345,...,0.0567
1028,0.3456,NA,...,0.0789

Subjects with fewer than 4 runs have "NA" for the missing run's conditions.

Product 2: Voxel Pattern .1D Files (Stage 5)

After Stage 5, each subject×ROI pair has a .1D file containing a matrix of shape (41 conditions × N voxels):

# sub-958 | ROI: vmPFC | voxels: 1245 | conditions: 41
# Extracted: 2026-03-14 18:51
# Row order matches condition_labels.txt
0.0853  0.1247  -0.0312  ...  0.0491   (1245 values = vmPFC voxels)
0.1102  0.0834  0.0178   ...  -0.0221  (condition 2)
...                                     (41 rows total)

To build a neural RDM: load the matrix, compute 1 − Pearson r between every pair of rows. The result is a 41×41 dissimilarity matrix.

import numpy as np
P = np.genfromtxt('sub-958_vmPFC_patterns.1D', comments='#')
# P.shape = (41, 1245)
neural_rdm = 1 - np.corrcoef(P)
# neural_rdm.shape = (41, 41)
