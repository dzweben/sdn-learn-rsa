Pipeline Overview

Pipeline Stages

The pipeline has 5 main stages plus QC and audit steps. Each stage has a dedicated script.

Stage 1: Fix Events

Relabel mislabeled nopred_fdbk events in BIDS files so timing generation works correctly.

Script: 1_fix_events.py

Stage 2: Timing Files

Build run-wise .1D timing files with feedback, prediction/response, and anticipation regressors.

Script: 2_generate_timing.sh

Stage 3: GLM

Run AFNI preprocessing (no smoothing) and GLM to produce per-subject stats files with 41 regressors.

Scripts: 3_run_glm.sh (calls 3a template + 3b fallback patch)

Stage 4: ROI Means

Extract mean beta coefficients from 8 anatomical ROI masks for each subject and condition.

Scripts: 4_extract_rois.sh (6 core) + 4b_extract_mentalizing_rois.sh (2 mentalizing)

Stage 5: Voxel Patterns

Extract full multi-voxel beta patterns from all 8 ROIs. These are the direct input for RSA.

Script: 5_extract_patterns.sh

What Stage 4 Produces (ROI Means)

Stage 4 produces 8 CSV files — one per ROI — each containing 38 subjects and 41 conditions. Each cell is a single number (the mean beta across all voxels in the mask).

What Stage 5 Produces (Voxel Patterns)

Stage 5 produces 304 .1D files (38 subjects × 8 ROIs). Each file is a matrix of shape (41 conditions × N voxels) where N depends on the ROI.

These pattern files are the direct input for RSA.

Execution Order

The safe order to run the full pipeline is:

  1. Fix events → 1_fix_events.py
  2. Generate timing → 2_generate_timing.sh
  3. Run GLM → 3_run_glm.sh
  4. Audit completion → check for missing stats, errors
  5. QC summary → qc_summary.sh
  6. Extract core ROI means → 4_extract_rois.sh
  7. Extract mentalizing ROI means → 4b_extract_mentalizing_rois.sh
  8. Extract voxel patterns → 5_extract_patterns.sh (RSA input)

Each stage depends on the previous one completing successfully. Never skip steps or run out of order.
