Overview

In this step we walk through the entire pipeline for one subject (958) to see what each stage produces. In practice, the batch scripts (Step 8) handle all subjects at once — but understanding the single-subject flow is essential.

Stage 1: Fix Events

Script: 1_fix_events.py
python3 scripts/1_fix_events.py \ --bids-dir /data/projects/STUDIES/LEARN/fMRI/bids \ --out-dir /data/projects/STUDIES/LEARN/fMRI/RSA-learn/bids_fixed \ --report reports/nopred_fdbk_fix_template.tsv \ --mode majority

This runs for ALL subjects at once (it's a batch operation). Check the output:

ls bids_fixed/sub-958/func/

Expected: corrected events.tsv files for each run.

Stage 2: Generate Timing

Script: 2_generate_timing.sh
bash scripts/2_generate_timing.sh

Also runs for all subjects. Check subject 958's timing files:

ls TimingFiles/Fixed2/sub-958/

Expected: NonPM_*.1D files (32 run-wise feedback), *_pred.1D and *_rsp.1D (8 pred/resp), and Anticipation_pred_fdk*.1D (anticipation).

cat TimingFiles/Fixed2/sub-958/Anticipation_pred_fdk.1D

Expected: 4 rows (one per run), each with onset:duration pairs.

Stage 3: Run GLM

Script: 3_run_glm.sh

The GLM script processes all subjects in parallel. For a single subject, it:

  1. Generates a proc script from the template (3a_afni_proc_template.sh)
  2. If fewer than 4 runs, patches via 3b_fallback_patch.py
  3. Runs AFNI preprocessing + GLM (this takes ~20-30 minutes per subject)
bash scripts/3_run_glm.sh

Check the output:

ls derivatives/afni/IndvlLvlAnalyses/958/958.results.LEARN_RSA_runwise_AFNI/stats.958+tlrc.*

Expected: stats.958+tlrc.HEAD and stats.958+tlrc.BRIK.gz

QC Summary

Script: qc_summary.sh
bash scripts/qc_summary.sh

Generates docs/qc-summary.md with per-subject QC metrics. Check subject 958:

grep "958" docs/qc-summary.md

Expected: one row with censor fraction, motion, TSNR, and other QC metrics.

Stage 4: Extract ROI Betas

Script: 4_extract_rois.sh (6 core ROIs)
bash scripts/4_extract_rois.sh

Extracts NZmean betas from 6 anatomical ROI masks for all subjects. Check subject 958:

grep "^958" derivatives/afni/ROI_extractions/vmPFC_betas.csv

Expected: one row with 41 beta values (no NAs for a 4-run subject).

Stage 4b: Extract Mentalizing ROI Betas

Script: 4b_extract_mentalizing_rois.sh (R-TPJ + dmPFC)
bash scripts/4b_extract_mentalizing_rois.sh

Same extraction for the 2 mentalizing ROIs. Check the output:

grep "^958" derivatives/afni/ROI_extractions/RTPJ_betas.csv
grep "^958" derivatives/afni/ROI_extractions/dmPFC_betas.csv

Expected: 41 beta values per ROI.

Stage 5: Extract Voxel Patterns

Script: 5_extract_patterns.sh (all 8 ROIs)
bash scripts/5_extract_patterns.sh

Extracts full multi-voxel beta patterns from all 8 ROI masks for all subjects. This is what RSA actually operates on.

Check the output for subject 958:

ls derivatives/afni/ROI_patterns/vmPFC/sub-958_vmPFC_patterns.1D

Expected: one .1D file exists.

head -4 derivatives/afni/ROI_patterns/vmPFC/sub-958_vmPFC_patterns.1D

Expected: a comment header line, then rows of space-separated voxel values (1245 values per row for vmPFC).

grep -c "^[^#]" derivatives/afni/ROI_patterns/vmPFC/sub-958_vmPFC_patterns.1D

Expected: 41 (one row per condition).

cat derivatives/afni/ROI_patterns/cross_validation.csv | grep "958" | head -3

Expected: rows showing OK status — the pattern means match the Stage 4 NZmean values.

Dry Run Mode

All extraction scripts support a dry run that verifies setup without running AFNI:

DRY_RUN=1 bash scripts/4_extract_rois.sh
DRY_RUN=1 bash scripts/4b_extract_mentalizing_rois.sh
DRY_RUN=1 bash scripts/5_extract_patterns.sh

Useful for checking that masks exist, sub-brick labels are found, and grids match before committing to the full extraction.
