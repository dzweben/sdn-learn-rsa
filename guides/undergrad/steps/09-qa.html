QA and Troubleshooting

How to confirm results are correct and recover from common failures.

GLM Quality Checks

After the GLM finishes, run these checks. No output = all clear.

1. Check for missing stats files
RESULTS=/data/projects/STUDIES/LEARN/fMRI/RSA-learn/derivatives/afni/IndvlLvlAnalyses TIMING=/data/projects/STUDIES/LEARN/fMRI/RSA-learn/TimingFiles/Fixed2 for d in $TIMING/sub-*; do id=${d##*sub-} stats="$RESULTS/$id/${id}.results.LEARN_RSA_runwise_AFNI/stats.${id}+tlrc.HEAD" [ ! -f "$stats" ] && echo "$id" done | sort -n

Any subject ID printed is missing its stats file.

2. Scan for real errors in output logs
RESULTS=/data/projects/STUDIES/LEARN/fMRI/RSA-learn/derivatives/afni/IndvlLvlAnalyses for f in $RESULTS/*/output.proc.*LEARN_RSA_runwise_AFNI; do id=$(basename "$(dirname "$f")") errs=$(grep -iE "ERROR|FATAL|FAILED|ABORT" "$f" \ | grep -viE "inverse.*error.*VERY GOOD|failed to load module matplotlib|apqc_title_info" \ | grep -c . || true) [ "$errs" -gt 0 ] && echo "$id: $errs real errors" done

Filters out known benign messages (matplotlib, QC cosmetics).

3. Verify anticipation regressor in every proc script
RESULTS=/data/projects/STUDIES/LEARN/fMRI/RSA-learn/derivatives/afni/IndvlLvlAnalyses TIMING=/data/projects/STUDIES/LEARN/fMRI/RSA-learn/TimingFiles/Fixed2 for d in $TIMING/sub-*; do id=${d##*sub-} proc="$RESULTS/$id/proc.${id}.LEARN_RSA_runwise_AFNI" if [ -f "$proc" ]; then [ $(grep -c "Anticipation.PredFdk" "$proc") -eq 0 ] && echo "MISSING anticipation: $id" [ $(grep -c "goforit" "$proc") -eq 0 ] && echo "MISSING goforit: $id" else echo "MISSING proc: $id" fi done

Confirms every subject has the anticipation regressor and -goforit 10.

ROI Extraction Validation

After running Stage 4, verify the output CSVs are correct:

Check ROI extraction outputs
# Check all 8 CSVs exist with correct dimensions wc -l derivatives/afni/ROI_extractions/*.csv

Expected: 39 lines each (1 header + 38 subjects).

# Check column count head -1 derivatives/afni/ROI_extractions/vmPFC_betas.csv | tr ',' '\n' | wc -l

Expected: 42 (Subject + 41 conditions).

# Check for NAs (should be 0 for full-run subjects, some for fallback subjects) grep -c "NA" derivatives/afni/ROI_extractions/vmPFC_betas.csv

Expected: a small number (only from subjects with fewer than 4 runs).

# Spot-check a value looks like a single float (not doubled) head -2 derivatives/afni/ROI_extractions/vmPFC_betas.csv | tail -1 | cut -d, -f2

Expected: a single number like 0.085360, not a doubled value like 0.0853600.085360.

Voxel Pattern Validation (Stage 5)

Stage 5 has a built-in cross-validation: for every subject × ROI × condition, it computes the mean of the extracted voxel pattern and compares it to the known-good NZmean value from Stage 4. If they match (within tolerance 0.001), the extraction is correct.

Check Stage 5 cross-validation
# Total .1D files (should be 304 = 38 subjects x 8 ROIs) ls derivatives/afni/ROI_patterns/*/sub-*.1D | wc -l

Expected: 304.

# Every .1D file should have exactly 41 data rows for f in derivatives/afni/ROI_patterns/*/sub-*.1D; do n=$(grep -c "^[^#]" "$f") [ "$n" -ne 41 ] && echo "BAD $f ($n rows)" done echo "Check complete"

Expected: only "Check complete" (no BAD lines).

# Cross-validation summary head -1 derivatives/afni/ROI_patterns/cross_validation.csv echo "---" grep -c "^OK" derivatives/afni/ROI_patterns/cross_validation.csv grep -c "^FAIL" derivatives/afni/ROI_patterns/cross_validation.csv

Expected: 12464 OK, 0 FAIL.

# Voxel counts per ROI cat derivatives/afni/ROI_patterns/voxel_counts.csv

Expected: vmPFC=1245, dACC1=46, dACC2=65, AntInsula=162, VS=107, Amygdala=98, RTPJ=438, dmPFC=81.

Known Benign Log Messages

These messages appear in GLM output logs but are safe to ignore:

MessageWhy It's Benign
Matrix inverse average error = ...e-14 ++ VERY GOOD ++ Numerical precision report, not an error
failed to load module matplotlib AFNI QC HTML rendering, does not affect GLM
'apqc_title_info' object has no attribute 'ses' AFNI QC cosmetic issue, does not affect GLM
