What Comes Next

The next phase uses the voxel pattern files for Representational Similarity Analysis (RSA):

  1. Build neural RDMs — Load each subject's .1D pattern matrix, compute 1 − Pearson r between all pairs of condition rows → a 41×41 dissimilarity matrix per subject per ROI
  2. Build model RDMs — Define theoretical similarity structures based on peer type, feedback type, and learning hypotheses
  3. Compare neural vs. model RDMs — Mantel test (Spearman correlation + permutation) to see which models explain the neural data
  4. Inter-subject RSA (IS-RSA) — For each condition, correlate voxel patterns between subjects. Subjects with similar social anxiety scores should have more similar neural patterns (Anna Karenina hypothesis)
  5. Group-level statistics — Test for significant effects across 38 subjects with permutation-based inference
# Quick-start: load patterns and build a neural RDM
