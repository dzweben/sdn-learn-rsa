Step 8

Batch Runs

Scale from one subject to all 38 subjects safely and reproducibly.

Batch Strategy

Each script already handles all subjects automatically. You do not need a separate batch wrapper — just run each stage script and it processes the full cohort.

The execution order is always:

  1. Fix events → 1_fix_events.py
  2. Generate timing → 2_generate_timing.sh
  3. Run GLM → 3_run_glm.sh (parallelizes across subjects)
  4. QC summary → qc_summary.sh
  5. Extract core ROI means → 4_extract_rois.sh
  6. Extract mentalizing ROI means → 4b_extract_mentalizing_rois.sh
  7. Extract voxel patterns → 5_extract_patterns.sh

Lab: Full Pipeline Run

Run the complete pipeline

Stage 1: Fix events

python3 scripts/1_fix_events.py \ --bids-dir /data/projects/STUDIES/LEARN/fMRI/bids \ --out-dir /data/projects/STUDIES/LEARN/fMRI/RSA-learn/bids_fixed \ --report reports/nopred_fdbk_fix_template.tsv \ --mode majority

Stage 2: Generate timing files

bash scripts/2_generate_timing.sh

Stage 3: Run GLM (longest step)

bash scripts/3_run_glm.sh

This runs all 38 subjects in parallel. Cap parallelism with: MAX_JOBS=4 bash scripts/3_run_glm.sh

QC summary

bash scripts/qc_summary.sh

Stage 4: Extract core ROI betas

bash scripts/4_extract_rois.sh

Stage 4b: Extract mentalizing ROI betas

bash scripts/4b_extract_mentalizing_rois.sh

Stage 5: Extract voxel patterns for RSA

bash scripts/5_extract_patterns.sh

Extracts full multi-voxel patterns from all 8 ROIs for all 38 subjects. Cross-validates against Stage 4 NZmean values. Runtime: ~3 minutes.

Monitoring Progress

Each script logs output. Check logs in real time:

Monitor batch progress

Lists all log files. The most recent is the current or last run.

tail -f logs/4_extract_rois_*.log

Follow the ROI extraction log in real time.

tail -f logs/5_extract_patterns_*.log

Follow the voxel pattern extraction log.

GLM Parallelism Controls

The GLM script (3_run_glm.sh) has environment variables to control parallelism:

VariableDefaultWhat It Does
MAX_JOBSCPU countMax number of subjects running simultaneously
MAKE_PROC1Set to 0 to skip proc script generation
CLEAN_OUT1Set to 0 to skip cleaning old outputs
RUN_GLM1Set to 0 to skip GLM execution
