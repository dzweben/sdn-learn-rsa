Folder Map

The pipeline produces outputs in a chain. Each stage writes to a specific folder:

FolderStageWhat's Inside
bids_fixed/ Stage 1 Corrected BIDS events.tsv files (mislabeled events fixed)
TimingFiles/Fixed2/ Stage 2 Run-wise .1D timing files per subject (onset:duration format)
derivatives/afni/IndvlLvlAnalyses/ Stage 3 Per-subject GLM results including stats.<id>+tlrc files
derivatives/afni/ROI_extractions/ Stage 4 8 CSV files with ROI mean beta coefficients (one scalar per condition)
derivatives/afni/ROI_patterns/ Stage 5 304 .1D files with voxel-wise beta patterns (one vector per condition — the RSA input)

Terminal Mapping

Explore the data layout by hand
cd
ls
ls scripts/
ls derivatives/afni/ROI_extractions/

Expected: 8 ROI beta CSV files (vmPFC_betas.csv, dACC1_betas.csv, etc.).

head -2 derivatives/afni/ROI_extractions/vmPFC_betas.csv

Expected: A header row with Subject and 41 condition names, then one data row.

ls derivatives/afni/ROI_patterns/

Expected: 8 ROI subdirectories (vmPFC/, dACC1/, etc.) plus manifest files.

ls derivatives/afni/ROI_patterns/vmPFC/ | head -3

Expected: .1D pattern files like sub-958_vmPFC_patterns.1D (38 total).

wc -l derivatives/afni/ROI_patterns/vmPFC/sub-958_vmPFC_patterns.1D

Expected: ~42 lines (1 header comment + 41 condition rows, each with 1245 voxel values).
